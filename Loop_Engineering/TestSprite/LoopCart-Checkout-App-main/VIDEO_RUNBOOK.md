# Video Runbook — Dedicated TestSprite Demo

## Before recording

1. Confirm `npm run build` passes.
2. Push the buggy starter project to GitHub.
3. Deploy it to a stable public production URL.
4. Confirm `SAVE20` visibly shows a $2 discount and a $98 total.
5. Create a TestSprite account and API key.
6. Verify the current TestSprite CLI commands from the official repository on recording day.
7. Prepare your coding agent, terminal font size, browser tabs, and deployment login.
8. Hide `FIX_REFERENCE.md` and the `solution` directory from the editor sidebar.

## Recording flow

1. Show the live buggy app.
2. Define loop engineering and identify verification as the feedback gate.
3. Show the TestSprite GitHub repository and Apache-2.0 license.
4. Install and set up the CLI.
5. Create a TestSprite frontend project with the public app URL.
6. Generate the checkout plan with the returned project ID.
7. Create and run the test.
8. Show the failed result.
9. Pull and inspect the failure bundle.
10. Ask the coding agent to fix the root cause without changing the requirement.
11. Build and deploy the fix.
12. Rerun the same TestSprite test until it passes.
13. Show the run history and close on the verifier lesson.
